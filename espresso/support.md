## Support scope

Totesoft supports installation, workflow configuration, eligible numeric fields, rule behavior, recent-run outcomes, field-context failures, permission errors, rate limits, and confirmed defects in supported Espresso versions.

Target initial response: {{SUPPORT_RESPONSE_TARGET}}. This is a service target, not a guaranteed SLA unless a separate written agreement says otherwise.

## Information to include

- Jira Cloud site URL or site identifier;
- Espresso version and environment, when known;
- company-managed or team-managed project type;
- workflow and transition name;
- source and target **field identifiers**;
- recent-run outcome code and timestamp;
- steps to reproduce; and
- sanitized screenshots or logs.

Do not send passwords, API tokens, complete issue exports, or unnecessary personal information. Redact numeric field values unless support specifically requires them and the customer authorizes their disclosure.

## Security reports

Report suspected security vulnerabilities to [{{SECURITY_CONTACT_EMAIL}}](mailto:{{SECURITY_CONTACT_EMAIL}}). Include a concise description, affected version, reproduction steps, and impact. Do not publicly disclose an unresolved vulnerability or include live customer data in the initial report.
