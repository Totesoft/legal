1. Espresso service

Espresso is a Jira Cloud workflow post function that an authorized Jira administrator can configure to read two numeric source fields after a workflow transition, apply a supported arithmetic operation, and write the result to a configured numeric target field. Current supported operations are addition, subtraction, multiplication, and division.
